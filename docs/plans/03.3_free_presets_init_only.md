# Plan: 03.3 — Free preset behaviour (INIT-only factory content, no Pro tier)

Status: done. Created 2026-11-10, after the preset-system review against `docs/plans/03_presets.md` and
`docs/plans/03.1_complete_plan03.md`, the fixes recorded in `docs/plans/03.2_preset_bar_layout_fix.md`, and the
review that found the remaining documentation drift.

Source of context:

- The review verdict and findings are in the session history for the preset-system review, and in
  `docs/plans/03.2_preset_bar_layout_fix.md` (§5, findings B–E, resolutions).
- The implementation under review: `modules/suite_presets/` (public seam, `factory_bank/`, CMake), the
  preset wiring in the three `plugins/<Name>` processors and editors, and the tests/docs that describe it.

Purpose of this plan: make the preset functionality available in the **free** version of every plugin, with
**no factory presets except one `INIT` preset per plugin**, and remove the Pro / private-overlay / paid-gating
framing from the build, the documentation and the tests.

---

## 0. Goal

Free users of the Spectral Drift Shifter, the Dynamic Saturation Companion and the Micro-Timing Chaos
Sequencer get the full preset feature surface:

- the preset bar in the header (`<` / `>` / name / INIT / SAVE, browser menu, right-click menu, dirty marker);
- user presets via `.ausp` (save, load, scan, sanitising, errors);
- one factory preset per plugin: **INIT**.

No private repository, no Pro overlay, no paid tier, no optional "bank" that carries paid content.

## 1. Current state vs. desired behaviour

| Current (2026-11-10) | Desired (this plan) |
|---|---|
| Bar, `.ausp` I/O, user presets, INIT, menu, dirty marker: public, always compiled (`modules/suite_presets`). | Unchanged — already free. |
| Embedded factory bank optional: `SUITE_PRESET_BANK` (default `OFF`) → free builds compile an **empty** bank (`PresetBank.cpp` returns `{}`); bank builds embed the 80-preset bank (`factory_bank/bank/AudioSuitePresets.xml`, 32 KB, 80 deltas). | The factory bank is **always embedded** and contains exactly **one INIT preset per plugin** (3 presets total). |
| Host program list behind `SUITE_PRESET_BANK_AS_PROGRAMS` (needs the bank); content = factory presets in bank order (Init + N). | Program list always compiled; content = Init + the one INIT preset per plugin (`getNumPrograms() == 2`). |
| Pro overlay skeletons | Already deleted in the working tree (03.2 finding C). |
| Docs / plan text still carry Pro framing (`SUITE_PRO_PRESETS`, private overlay, `presetSeamUnavailable`). | Updated as part of this plan (section 4.4). |

## 2. Desired behaviour per plugin

For each of the three plugins (Spectral Drift Shifter, Dynamic Saturation Companion, Micro-Timing Chaos):

- `SuitePresets::isAvailable() == true`.
- `PresetBar::getPreferredHeight() == 30`.
- `PresetBank::getNumFactoryPresets() == 1` — the INIT preset.
- The bar's INIT button and the factory menu entry both address the INIT state (the synthetic `applyInit()`
  path and the bank INIT preset must agree; a bank INIT preset whose state equals the defaults is the free
  factory content).
- Host program list (when compiled): program 0 = Init, program 1 = the plugin's INIT preset.

## 3. Design decisions

- **D1 — the INIT factory preset.** Add one real bank preset per plugin named `INIT`, with a delta equal to
  the default state and metadata (name / category / description). It is exempt from the `bankNotDefault` /
  `audit_bank.py` "no preset equal to the default" rule through an explicit INIT exception; the bar's synthetic
  INIT (`applyInit()`, empty `<PARAMETERS>` tree) remains the runtime path for the INIT button.
- **D2 — host program list.** Keep the `PresetPrograms` machinery; with an INIT-only bank it yields
  `Init + INIT`. The `SUITE_PRESET_BANK_AS_PROGRAMS` flag is removed and the list is always compiled.
- **D3 — build flags.** Remove the `SUITE_PRESET_BANK` and `SUITE_PRESET_BANK_AS_PROGRAMS` CMake options and
  their refusal rule; `suite_presets_add_to_target` always adds the `SuitePresetBankData` binary-data target
  and defines the bank/program flags as on.

## 4. Implementation steps

### 4.1 Authoring and factory bank content

1. `tools/preset_data.py`: replace the 80-preset `PRESETS` authoring set with the free content — one INIT
   preset per plugin (delta = defaults; `_name = "INIT"`; a category; a description). Keep only the routing
   schema (`SCHEMA`) needed to author INIT states.
2. `python tools/build_bank.py` → regenerate `modules/suite_presets/factory_bank/bank/AudioSuitePresets.xml`
   and the per-plugin JSON files (one INIT JSON per plugin).
3. `python tools/audit_bank.py` → update the rules for the new content: expected counts (1 per plugin, 3
   total), INIT exemption from the not-default rule, category handling for a single-entry bank.

### 4.2 Build wiring

1. `CMakeLists.txt` (root): remove the `SUITE_PRESET_BANK` / `SUITE_PRESET_BANK_AS_PROGRAMS` options, the
   `SUITE_PRESET_BANK_AS_PROGRAMS`-needs-bank refusal, and the `if(SUITE_PRESET_BANK)` block that embeds the
   bank (the bank is now always embedded).
2. `modules/suite_presets/SuitePresets.cmake`: always add
   `Source/PresetBar.cpp`, `Source/PresetFile.cpp`, `factory_bank/Source/PresetBank.cpp`; always add the
   `factory_bank` include dir; always define `SUITE_PRESET_BANK=1` and link `SuitePresetBankData`; always
   define `SUITE_PRESET_BANK_AS_PROGRAMS=1` (program list compiled).
3. `modules/suite_presets/factory_bank/CMakeLists.txt`: unchanged target definition (`SuitePresetBankData`).
4. `modules/suite_plugin/SuitePlugin.cmake`: register the `<Name>PresetTests` executable whenever
   `SUITE_BUILD_TESTS` (drop the `AND SUITE_PRESET_BANK` condition).
5. `plugins/<Name>/Source/PluginProcessor*.cpp`: remove the `#if SUITE_PRESET_BANK_AS_PROGRAMS` guards so the
   program-list behaviour is unconditional (behaviour unchanged: Init + bank presets).

### 4.3 Tests

1. `plugins/<Name>/tests/PluginTests.cpp`: remove the `#if SUITE_PRESET_BANK` / `#if ! SUITE_PRESET_BANK_AS_PROGRAMS`
   blocks in `testPresetBar`; the unconditional version asserts:
   - `SuitePresets::isAvailable() == true`;
   - `bar.getPreferredHeight() == 30`;
   - `bar.getNumFactoryPresets() == 1` (the INIT preset);
   - with the program list compiled: `processor.getNumPrograms() == 2`, `getProgramName(0) == "Init"`,
     `getProgramName(1) == "INIT"`.
2. `modules/suite_presets/factory_bank/tests/PresetTestUtils.h`: update the `runBank*` helpers for an
   INIT-only bank — `runBankShape` (per-plugin factory slice == 1), `runBankNotDefault` (INIT exempt),
   `runBankRanges` (INIT values inside the live ranges), `runApplyMatchesFile`, `runApplyResetsMissing`,
   `runApplyTwiceIdempotent`, `runAudioSanity`, `runMidiSanity`, `runEditorWithBar`, `runMenuModel`,
   `runProgramList` (Init + the INIT preset).
3. `modules/suite_presets/factory_bank/tests/MicroTimingChaosPresetTests.cpp`: point `testMtcCurveRestored` at
   the INIT preset / synthetic curve; `testMidiSanity` iterates the single INIT preset (default density 70 %
   still fires).

## 5. Expected impact

- The default (`SUITE_BUILD_PLUGINS=ON`) build embeds the INIT-only bank and compiles the program list, so
  the plugin preset tests are registered unconditionally: CTest entry count returns to the "bank" shape
  (11 public + 3 `<Name>PresetTests` = 14 entries) with INIT-only content, instead of the current 11 public /
  14 bank split.
- No new APVTS parameters; plugin `numControls` / `checkParameterIds` unchanged.
