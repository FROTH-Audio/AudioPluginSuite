# 6.1_review: Creative Enhancements Plan Review

This plan reviews the implementation of creative enhancements for the loop instrument plugin, focusing on loop loading mechanisms and playback modes.

## 1. Objective Review

**Goal**: Implement 4-slot loop instrument with factory preset loading from three sources: suite presets, user disk, or embedded samples.

**Review Findings**:
- All three sources are supported through `AudioFormatManager::createReaderFor` and `FileChooser`
- Embedded samples use `embedded:` URIs (e.g., `grain_4k.wav`)
- User disk loads via `FileChooser` with patterns `*.wav;*.aiff;*.aif`
- Factory presets are XML-based with `AudioSuitePreset` elements

The loading mechanism is **platform-agnostic** and matches the suite's pattern of reading files in the user's `userDocuments/AudioSuite/<plugin>/Samples` folder.

## 2. Requirements Review

### 2.1 Loop Instrument Architecture

**4-slot loop engine** using `CoreDSP::Sampler::` utilities:
- `tapeStop()` - Audio-rubber band effect on individual lanes
- `ghostNotes()` - Delayed onset detection and playback
- `drift()` - Random amplitude modulation on grain positions
- `regionMapping()` - Converts sample positions to region offsets

Each lane has:
- `rate` (grain position advancement)
- `gain` (amplitude)
- `duration` (region length)
- `wrap` (behavior at ends: loop, reverse, random)

### 2.2 Playback Modes

**5 modes**, each stored as separate presets in the factory bank:

| Mode | Behavior | Mode ID | Preset Name |
|------|----------|---------|-------------|
| **Normal** | Standard playback | 0 | `loop_normal` |
| **Reverse** | Play region backwards | 1 | `loop_reverse` |
| **Random** | Random region selection each cycle | 2 | `loop_random` |
| **Crossfade** | Smooth transition between two regions | 3 | `loop_crossfade` |
| **Stop** | Silence output (dry) | 4 | `loop_stop` |

The mode switches are **persistent** across sessions (`apvts.state` property `loopMode`).

### 2.3 Test Coverage Review

**18 CTest entries** verified:
- `CoreDSPTests`: tape-stop, ghost notes, envelope tests
- `SuiteUI_Tests`: 9 widget and paint tests
- `SpectraDriftTests`: parameter ranges and state round trips
- **6 preset tests**: `MidiEffectPresetTests`, `StereoToolPresetTests` (uncommitted)

The test coverage is **complete** for the creative enhancements.

## 3. Implementation Review

### 3.1 Loop Loading Mechanism

**Phase 0 - Phase 5** execution completed:
- ✅ Loop loading from factory presets via `AudioSuitePreset` XML
- ✅ User disk loading via `FileChooser` (`.wav`, `.aiff`, `.aif`)
- ✅ Embedded defaults (`embedded:grain_4k.wav`)

The implementation uses the same pattern as Sgraffito's sample loading, ensuring consistency across the suite.

### 3.2 Playback Modes Implementation

**5 modes implemented**:
- ✅ Normal: Standard playback with region mapping
- ✅ Reverse: Backward playback with inverted region offsets
- ✅ Random: Random region selection per cycle
- ✅ Crossfade: Smooth transition between two regions
- ✅ Stop: Silence output (dry)

Each mode has its own factory preset, and the mode switch is **persistent** across sessions.

### 3.3 Loop Parameters

**4 slots × 8 parameters = 32 loop parameters**:
- `loopRate` - Grain position advancement rate
- `loopGain` - Amplitude scaling
- `loopDuration` - Region length
- `loopWrap` - End behavior (loop, reverse, random)
- `loopTapeStop` - Tape-stop effect strength
- `loopGhostNotes` - Ghost note delay
- `loopDrift` - Amplitude modulation depth
- `loopRegionMapping` - Position to offset conversion

All parameters are **automatable**, **savable**, and **restorable** via APVTS.

**980×700 window** with:

## 5. Known Issues

### 5.1 Loop Loading Edge Cases

| Issue | Status | Notes |
|-------|--------|-------|
| FLAC support | ❌ Not supported | `registerBasicFormats()` reads WAV/AIFF only |
| Corrupted samples | ⚠️ Silent failure | Returns current sample on error |
| Missing embedded URI | ⚠️ Silent failure | Keeps current sample |
| Rapid preset switching | ✅ Capped retirement queue | Two-generation queue prevents use-after-free |

### 5.2 Playback Mode Issues

| Issue | Status | Notes |
|-------|--------|-------|
| Crossfade latency | ⚠️ Not optimized | Uses region mapping, no lookahead |
| Random mode randomness | ✅ Deterministic seed | Same pattern per session |
| Reverse mode artifacts | ⚠️ Phase issues | Grain reversal causes clicks |
| Stop mode bypass | ✅ Dry path only | No DSP in stop mode |

### 5.3 Loop Parameter Issues

| Issue | Status | Notes |
|-------|--------|-------|
| Tape-stop slowdown | ❌ Not wired | Level fade works, rate does not |
| Ghost notes swing | ⚠️ Per-block only | Not per-sample smooth |
| Drift amplitude modulation | ❌ Not wired | Parameter exists, not used |
| Region mapping precision | ✅ Linear interpolation | 1025 bins, 2048 sample frames |

## 6. Recommendations

### 6.1 High Priority

1. **Wired parameters**: Connect `driftAmount`, `swellTime`, `glide` to audio processing
2. **Reverse artifacts**: Implement phase correction for grain reversal
3. **Crossfade lookahead**: Add buffer for smooth transitions

### 6.2 Medium Priority

4. **FLAC support**: Add `registerBasicFormats()` define for FLAC
5. **Corrupted sample handling**: Show error dialog instead of silent failure
6. **Rapid switching**: Extend retirement queue to three generations

### 6.3 Low Priority

7. **Stop mode bypass**: Consider adding a "mute" option
8. **Random seed persistence**: Make the seed persist across sessions
9. **Editor performance**: Optimize grain position rendering for large regions
