# Plan: 03.4 — Remove all "Pro" references; presets fully free

Status: done. Created 2026-11-10, after plan 03.3 (free preset behaviour, INIT-only factory content)
was superseded by the decision to keep the full 80-preset bank as an optional shippable feature.

Purpose: eliminate every `SUITE_PRO_PRESETS` / `SUITE_PRO_PRESETS_AS_PROGRAMS` / `SuitePresetsPro`
/ `pro_preset_bank` / "Pro build" / "paid tier" / "private overlay" reference from documentation,
CI, and plans. Presets are now fully free with an optional factory bank behind
`SUITE_PRESET_BANK` / `SUITE_PRESET_BANK_AS_PROGRAMS` (already the case in code). No Pro licence,
no Pro overlay, no paid gating remains anywhere.

---

## 0. Decisions

| Question | Decision |
|---|---|
| Pro build | Removed. There is no "public" vs "Pro" split — the bar, `.ausp` I/O, user presets, and menu ship in every build. |
| Factory bank | Optional (`SUITE_PRESET_BANK`, default `OFF`); 80 presets embedded when on. |
| Host program list | Optional (`SUITE_PRESET_BANK_AS_PROGRAMS`, needs the bank); program 0 = Init, 1..N = factory presets. |
| Licence | GPL v3 for code. No overlay, no paid preset data product framing in docs. |
| Bank location | `modules/suite_presets/factory_bank/bank/` (already in place). |
| Tooling | `tools/build_bank.py`, `tools/audit_bank.py` write to `factory_bank/bank/` (already in place). |
