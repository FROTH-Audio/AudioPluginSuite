# Factory bank — embedded factory presets (free, full bank)

This directory holds the **embedded factory bank** for the FROTH Audio preset system.
The preset bar, the `.ausp` file I/O and the menu model are public and live in
`modules/suite_presets` (`include/`, `Source/`, `tests/`); see `AGENTS.md` §5.5.

The bank is **flag-gated**: the root option `SUITE_PRESET_BANK` (default `OFF`) links the
embedded bank into the plugin binaries; `SUITE_PRESET_BANK_AS_PROGRAMS` additionally exposes
it as the host program list. Without the flag the plugins build with an empty bank (the bar
reports height 0). CI and the release workflow build with the flag on, so published binaries
carry the full bank (owner decision, 2026-11-12: the full bank ships). No Pro overlay, no
paid tier.

## Layout

```
factory_bank/
  include/PresetBank.h          PresetBank (getFactoryPresets, parseDelta) and PresetPrograms
  Source/PresetBank.cpp         Bank parse and program list; degrades to an empty bank without the flag
  bank/AudioSuitePresets.xml    The embedded bank payload: 160 presets (26 SD / 26 DS / 28 MTC / 20 Sgraffito / 15 each for MidiEffect, StereoTool, MultibandSaturation and Cyclical)
  bank/<plugin>/<slug>.json     One delta JSON per factory preset (authoring source)
  tests/PresetTestUtils.h       Shared runBank*/runApply*/runProgramList/runMenuModel helpers
  tests/<Name>PresetTests.cpp   Per-plugin bank tests, registered by suite_add_plugin (bank build only)
```

## How it builds

`juce_add_binary_data(SuitePresetBankData)` is the one real target here. The root
`CMakeLists.txt` adds it in the `SUITE_PRESET_BANK` block, because the flag gates the link.

`suite_presets_add_to_target(<target>)` in `modules/suite_presets/SuitePresets.cmake` compiles
`PresetBank.cpp` (together with the public `PresetBar.cpp` and `PresetFile.cpp`) into each
consumer, defining `SUITE_PRESET_BANK=1` and linking `SuitePresetBankData` when the flag is on,
or `SUITE_PRESET_BANK=0` without it (the bank degrades to empty).

There is no static library — like `suite_ui` and `suite_modulation`, the sources compile directly
into each consumer to avoid duplicate-symbol link errors with JUCE. The data target namespace is
`SuitePresetBankData` (not `BinaryData`) so it does not collide with each plugin's
`<Name>Assets` binary-data target.

## Factory bank content

The bank carries **160 factory presets**: 26 Spectral Drift, 26 Dynamic Saturation, 28
Micro-Timing Chaos, 20 Sgraffito and 15 each for the MIDI Chord Arp Scale Tool, Stereo Tool
Effect, Multiband Saturation and Cyclical. Each plugin's list starts with its `INIT` preset
(name `INIT`, category `Utility`, description `The default state.`) — an empty delta, exempt
from the not-default audit rule. New presets are appended at the end of each plugin's list;
bank order is append-only once hosts cache program indices. Plan 05.3 F1.3 added five Sgraffito
presets (Velvet Swing, Ghostly Echo, Held Breath, Fine Grained Drift, Slow Attack Tape), taking
the suite from 95 to 100; plan 6.1 and plan 11 added the MIDI effect, stereo tool, Multiband
Saturation and Cyclical lists, taking it to 160. The authoring source is `tools/preset_data.py` (`SCHEMA` +
`PRESETS`). Regenerate with:

```
python tools/build_bank.py
python tools/audit_bank.py
```

`audit_bank.py` enforces: unique names per plugin, at least three categories per plugin, every
value inside the parameter's `NormalisableRange`, no preset equal to the default state (INIT
exempt), Spectral Drift `freeze` only in `Freeze`, Dynamic Saturation `drive` 24 + `fold` 50
only in `Extreme`, Micro-Timing Chaos host `sync` off and `bpm` 120 in every factory preset,
base patterns that fire at least one step, a `samplePath` on a preset only as an `embedded:`
URI and never a file path (plan 07 Q3, revised in phase 4; checked in the authoring data,
the generated XML attributes and the JSON files), and — since plan 05.2 — that the authoring
schema covers every parameter the plugins expose (live IDs parsed from the sources, the shared
Router's parameters included).

Every Sgraffito preset carries its own generated sample (`embedded:<slug>_4k.wav`,
plan 10 phase 7): selecting a preset loads the sample it was made with, and INIT resets
to the embedded default (`grain_4k.wav`). The 20 samples are generated by
`tools/sgraffito_samples.py`, one per preset, each designed to showcase the preset.
`SgraffitoPresetTests` applies every URI in the bank and asserts it loads.

## Host program list

Behind the separate `SUITE_PRESET_BANK_AS_PROGRAMS` flag: program 0 is Init (every parameter
at its default) and programs 1..N are the factory presets in bank order.
`setCurrentProgram(i)` applies preset i; `getCurrentProgram()` tracks the last applied index
(-1 after any state change that isn't a factory program). Bank order is append-only once
hosts cache indices.
